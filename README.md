Predictive maintenance (PdM) memanfaatkan data sensor untuk mengantisipasi kegagalan lebih dini sehingga perawatan dapat dilakukan secara proaktif. Studi ini mengembangkan pipeline PdM end-to-end yang menghasilkan skor risiko kegagalan dari data tabular multisensor serta menjelaskan skor tersebut secara actionable (dapat ditindaklanjuti). Menggunakan dataset publik Kaggle tentang machine downtime (~2.500 rekaman), target didefinisikan sebagai kegagalan pada langkah berikutnya (next-step failure, y_next) dengan menggeser label satu langkah ke depan di dalam setiap Machine_ID. Pemisahan data berbasis waktu diterapkan untuk meniru kondisi implementasi nyata dan mencegah data leakage. Tiga model dievaluasi, Regresi Logistik, HistGradientBoosting, dan Random Forest, dengan keluaran probabilitas sebagai skor risiko serta metrik yang berfokus pada pemeringkatan risiko (PR-AUC) ditambah presisi/recall. Random Forest mencapai performa terbaik (PR-AUC 0,462; presisi 0,528; recall 0,571 pada ambang 0,5). Threshold sweeping digunakan untuk menyeimbangkan beban inspeksi versus kegagalan yang terlewat, dengan menerjemahkan ambang menjadi volume peringatan harian dan prioritas mesin. Interpretabilitas melalui permutation importance menyoroti klaster pendorong utama (torsi–pemotongan–getaran) serta subsistem pendukung (coolant, hidrolik, kelistrikan), yang dipetakan ke dalam daftar periksa inspeksi untuk mengubah peringatan menjadi alasan yang jelas dan tindakan rekomendasi.
