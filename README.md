Predictive maintenance (PdM) uses sensor data to anticipate failures early so maintenance can be done proactively. This study develops an end-to-end PdM pipeline that produces a failure risk score from multi-sensor tabular data and explains the score in an actionable way. Using a public Kaggle machine downtime dataset (~2,500 records), the target is defined as next-step failure (y_next) by shifting labels one step ahead within each Machine_ID. A time-based split is applied to mimic real deployment and prevent data leakage. Three models are evaluated, Logistic Regression, HistGradientBoosting, and Random Forest, using probability outputs as risk scores and metrics focused on risk ranking (PR-AUC) plus precision/recall. Random Forest achieves the best performance (PR-AUC 0.462; precision 0.528; recall 0.571 at threshold 0.5). Threshold sweeping is used to balance inspection workload versus missed failures, translating thresholds into daily alert volumes and machine priorities. Interpretability via permutation importance highlights key driver clusters (torque–cutting–vibration) and supporting subsystems (coolant, hydraulics, electrical), which are mapped into an inspection checklist to turn alerts into clear reasons and recommended actions.
